# Cutting

Онлайн-приложение для прямоугольного раскроя листовых материалов.

## Быстрая навигация

- `index.html` — единственная HTML-точка входа.
- `src/` — разрабатываемые JavaScript и CSS-файлы.
- `tests/` — Node.js-тесты алгоритма и интерфейсных сценариев.
- `assets/` — изображения интерфейса.
- `docs/` — документация, которую читать только по теме задачи.
- `.codex/SESSION.md` — текущее состояние и следующий шаг.
- `.codex/DECISIONS.md` — зафиксированные решения.
- `.codex/KNOWN_ISSUES.md` — подтверждённые проблемы.

## Правила экономии контекста

1. Сначала читай этот файл и `.codex/SESSION.md`.
2. Ищи по имени функции, DOM-id или ключевой строке; не сканируй весь проект без причины.
3. Открывай только связанные файлы и нужные фрагменты.
4. Перед изменением проверь текущую реализацию и зависимости.
5. Делай минимальную правку, не переписывай рабочие модули.
6. После изменения запускай релевантные тесты.
7. Не добавляй зависимости без явной необходимости.
8. Не включай `logs/` и `temp/` в анализ и коммиты.

## Проверка

```powershell
node tests/optimizer.test.js
node tests/search-ui.test.js
node tests/drag-transfer.test.js
```

Подробности: `docs/architecture.md`, `docs/testing.md`.

## Handoff

Перед завершением заметной задачи обнови `.codex/SESSION.md`: цель, сделанное, проверенное, проблемы и следующий шаг. Не превращай файл в историю — перезаписывай его кратким актуальным состоянием.
