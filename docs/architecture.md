# Архитектура

## Поток запуска

`index.html` подключает AG Grid, затем модули из `src/` в порядке зависимостей. Проект использует обычные `<script>` без сборщика и модульной системы.

## Основные зоны

- `src/optimizer.js` — подготовка данных, поиск раскладки, проверка геометрии и резов.
- `src/app.js` — состояние приложения, расчёт, рендеринг и взаимодействие с раскладкой.
- `src/db.js` — локальное хранение данных браузера.
- `src/search-ui.js` — параметры поиска и запуск расчёта.
- `src/table-rows.js` — строки таблиц деталей и листов.
- `src/material-*.js` — база материалов и формы материалов.
- `src/edge-column.js` — кромки и связанный UI.
- `src/styles.css`, `src/edge-column.css` — стили.

Порядок `<script>` в `index.html` считается частью архитектуры: сначала утилиты и состояние, затем UI-модули.
