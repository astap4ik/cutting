# Тестирование

Тесты запускаются напрямую Node.js из корня проекта:

```powershell
node tests/optimizer.test.js
node tests/search-ui.test.js
node tests/drag-transfer.test.js
```

`optimizer.test.js` проверяет геометрию, материалы, повороты, режимы и валидацию резов. `search-ui.test.js` проверяет расчёт через минимальную DOM-модель. `drag-transfer.test.js` проверяет перенос деталей и обработчики перетаскивания.

Для UI-проверки открой `index.html` через статический сервер и проверь импорт деталей, расчёт, перетаскивание, базу материалов и сохранение в браузере.
